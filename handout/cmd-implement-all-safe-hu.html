/implement-all-safe

← Vissza az áttekintéshez

Összefoglaló

Runtime-független portable ciklus, amely ismételten lefuttatja a /implement-next parancsot egy tervfájlon — minden lépését inline, a jelenlegi kontextusban végrehajtva, subagent indítása nélkül. Bármilyen harness-ben (Claude Code, Cursor, claude -p) működik, hook-függőség nélkül, és ez az a mód is, amelyre a /implement-all automatikusan átvált, ha az Agent tool nem elérhető (Cursor, claude -p, Claude Code < 2.1.172).

Mikor használd

Akkor használd közvetlenül a /implement-all-safe parancsot, ha a harness-ednek nincs subagent-primitívje a feladatok indításához, vagy ha a /implement-all a verzióellenőrzése után már ezt választotta ki helyetted.

  • Cursorban, claude -p-ben vagy más olyan harness-ben futtatsz, amelyben nincs Agent/Task tool.
  • A Claude Code buildod régebbi, mint 2.1.172, ezért az Agent tool nem használható feladatonkénti subagentekhez.
  • A /implement-all automatikusan ezt a parancsot hívta meg, miután a -1. lépés verzióellenőrzése azt találta, hogy a CLAUDE_CODE_EXECPATH nincs beállítva, vagy a verzió túl régi.

Kritikus megszorítások (a parancs maga kényszeríti ki):

  • NEM indít subagenteket — minden feladat minden lépése inline, a jelenlegi kontextusban fut le.
  • Ciklusonként PONTOSAN EGY feladatot implementál — nincs előkészítés vagy előretekintés a következő feladatokra.
  • Ha egy feladat checkboxa nem billen át, ugyanazt a feladatot próbálja újra (nem a következőket), legfeljebb 3 kísérletig, utána megáll és jelenti: "Manual intervention required."

Hívás

Egyetlen argumentumként add át a tervfájl elérési útját.

/implement-all-safe [plan-file-path]

Paraméterek:

  • [plan-file-path] — (kötelező) A terv Markdown-fájljának elérési útja, vagy egy kulcsszó, ha a pontos elérési út nem ismert.

Folyamat (0. lépés + ciklus):

  1. 0. lépés — Tervfájl feloldása: Ha az argumentum egy létező fájl elérési útja, azt használja. Egyébként a **/*.md mintára illesztett kulcsszó-egyezést keres olyan jelöltek között, amelyek tartalmaznak legalább egy be nem pipált taskot. Megáll és kérdez, ha egyértelműség nélkül több vagy egy találat sincs.

Ciklustörzs (addig ismétlődik, amíg a plan-progress.sh exit 1-et nem ad — minden feladat kész):

  1. Haladás: Lefuttatja a bash ~/.claude/scripts/plan-progress.sh <plan-file> parancsot, és megjeleníti a kimenet első két sorát szó szerint, átformázás nélkül. Exit 1 → minden kész, megáll. Exit 2/3 → hibajelentéssel megáll. Exit 0 → megjegyzi a NEXT_TASK_NAME-et és folytatódik.
  2. Következő feladat implementálása (inline): Kiírja: Starting task <NEXT_TASK_NAME> at [HH:MM:SS], majd közvetlenül, a jelenlegi kontextusban futtatja a /implement-next parancsot — subagent nem indul. Ugyanazok a szkóp-szabályok érvényesek, mint a /implement-all-nál: pontosan egy feladat, és a kör csak akkor ér véget, ha az implementáció, a /iterative-review, a zöld tesztek, a checkbox átbillentése, egyetlen commit és a /implement-next 7. lépésének riportja mind megtörtént.
  3. Recovery check — landolt-e a feladat: Ellenőrzi, hogy a task ki van-e pipálva a tervfájlban, és hogy a kapcsolódó fájlok commitolva vannak-e. Ha nincs kipipálva, visszatér a 2. lépéshez és újrapróbálja (legfeljebb 3 kísérletig, utána megáll és jelenti, hogy manuális beavatkozás szükséges). Ha ki van pipálva, de nincs commitolva, csak az adott feladathoz tartozó fájlokat commitolja, explicit elérési út alapján (soha nem git add -A-val), és jelenti azt anomáliaként.

Kapcsolódó eszközök

  • /implement-all — A verzióérzékeny wrapper: subagentet indít feladatonként, ha az Agent tool elérhető (Claude Code ≥ 2.1.172), egyébként erre a parancsra vált vissza.
  • /implement-next — Az egyfeladatos implementációs parancs, amelyet ez a ciklus feladatonként inline lefuttat; TDD-t, kritikai review-t, teszteket, kipipálást és commitot futtat.
  • /iterative-review — Devil's advocate review-ciklus, amelyet az /implement-next hív meg minden feladat implementációja során.
  • scripts-plan — A plan-progress.sh szkript, amelyet minden iteráció elején meghív.
