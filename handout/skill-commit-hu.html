/commit

← Vissza az áttekintéshez

Összefoglaló

Ne írj commit üzeneteket kézzel. Beolvassa a staged difft, elkészít egy Conventional Commits üzenetet egy miért-first törzzsel, majd vagy azonnal commitol, vagy csak a szöveget adja vissza — te döntöd el.

Mikor használd

Elkészültél egy változtatással, és olyan commit üzenetre van szükséged, amely a miértet magyarázza el, nem csak a mitet. Használd a /commit parancsot, ha egyszerre akarod legeneráltatni és commitolni, vagy a /commit message parancsot, ha csak a szöveget akarod a repo érintése nélkül.

Triggerkifejezések (a SKILL.md-ből):

  • "write a commit message"
  • "draft a commit message"
  • "what should the commit message be?"
  • "commit message for these changes"
  • "commit it"
  • "go ahead and commit"

Két mód: sima /commit generál és commitol; /commit message csak a szöveget állítja elő — a repo-t nem érinti.

Meghívás

Commit mód — generálás és commit:

/commit

Vázlat mód — csak az üzenet szövege, git-mutáció nélkül:

/commit message

A skill beolvassa a staged difft (vagy az unstaged változtatásokat, ha nincs semmi staged). Az üzenet alakja: <type>(<scope>?): <imperatív leírás> subject sor + egy vagy több ## H2 törzs-szekció, mindegyik egy kontextus bekezdéssel majd bullet-ekkel. Típusok: feat, fix, docs, refactor, chore, test, perf.

1. példa — Commit mód (szemléltető példa)

Bemenet:

/commit

Kimenet / Eredmény:

Commit mode: I will commit after generating the message.

```
docs(readme): document 8 previously undocumented skills

## README coverage

Eight skills existed in `skills/` with no entry in the "What it
gives you" section. Readers had no way to discover them without
opening raw SKILL.md files directly.

Added a pain-first bullet for each skill, placed in the section
that best matches its purpose:

- "Ship a feature, start to finish": `/quick-plan`, `/commit`,
  `/wrap-up`
- "Get a second opinion": `/clean-code-review`, `/options`
- "Wrangle docs and skills": `/doc-voice`, `/md-reviewer`,
  `/plain-language`
```

6c5d1ed docs(readme): document 8 previously undocumented skills
 README.md | 8 ++++++++

2. példa — Vázlat mód (szemléltető példa)

Bemenet:

/commit message

Kimenet / Eredmény:

Draft mode: I will generate the message only — no commit.

```
feat(api): add POST /users/bulk endpoint for batch creation

## Batch user creation

Creating users one at a time via POST /users was too slow for
import flows — a 500-row CSV took ~25 s of sequential requests.
The new endpoint accepts up to 1 000 user objects in one call.

- New route: `POST /users/bulk` in `src/routes/users.py`
- Validates each row individually; partial failures return per-row
  errors without rolling back successful rows
- Added integration tests: `tests/test_users_bulk.py` (12 cases)
```

Paste into `git commit -F-` or `git commit -e` to review.

Kapcsolódó eszközök

  • /wrap-up — Munkamenet-záró audit, amely teszteket és devil's-advocate-et futtat, majd felszínre hozza a nem commitolt munkát és rákérdez — csak explicit igen után commitol.
  • /implement-next — Minden plan-taskot test-first épít fel, és a saját 6. lépésében közvetlenül commitolja — egy task, egy commit.
  • /bugfix — Utolsó mutáló lépésként a /commit-ot hívja, a végső riport előtt, a bukó teszt, a TDD javítás, a doksi-frissítés és a review-kör után.
