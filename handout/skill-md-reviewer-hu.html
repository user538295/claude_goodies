Összefoglaló

A dokumentáció elcsúszik — a szakkifejezések változnak, a kereszthivatkozások elavulnak, ellentmondások halmozódnak fel. A /md-reviewer Markdown-fájlokat auditál: konzisztenciát, ellentmondásokat és elavult hivatkozásokat keres, mielőtt az olvasók rábukkannak. 50+ fájlos készleteket is kezel, folytatható feldolgozással, és képes követő dokumentumokat egy tekintélyes mester ellen validálni.

Mikor használd

Akkor érdemes az /md-reviewer-t használni, ha a dokumentáció már túlnőtt azon, amit szemre ellenőrizhetnél: a terminológia elcsúszott, ellentmondást gyanítasz az oldalak között, vagy az átnevezések óta esetleg elavultak a kereszthivatkozások. Lefedi: terminológia-konzisztencia, logikai ellentmondások, kereszthivatkozás-érvényesség, formázási szabványok, hang/stílus elemzés, technikai pontosság és duplikáció-detektálás.

Triggerkifejezések (a SKILL.md-ből):

  • "review my documentation"
  • "check docs for inconsistencies"
  • "validate markdown files"
  • "find contradictions in docs"
  • "audit documentation quality"

Mester-követő mód: jelölj ki egy dokumentumot mérvadónak (pl. README.md), és az összes többi ehhez képest kerül ellenőrzésre. A találatok súlyosság szerint vannak jelölve: ellentmondás, eltérés, elavult hivatkozás, formázási hiba.

Meghívás

Hívd meg közvetlenül, majd írd le a felülvizsgálandó dokumentumokat — vagy illeszd be az elérési utakat:

/md-reviewer

A skill két beállítási kérdést tesz fel indítás előtt: mely fájlokat vizsgálja, és van-e egy mérvadó mester dokumentum. Nagy készletek esetén (50+ fájl) nyomon követi a haladást, így szünet után folytathatod az elejéről való újraindítás nélkül.

1. példa — Mester-követő felülvizsgálat

Bemenet:

/md-reviewer
check docs/ for inconsistencies — README.md is the master

Kimenet / Eredmény:

Setup
────────
Master: README.md
Followers: docs/architecture.md, docs/api.md, docs/install.md (3 fájl)

README.md feldolgozása mesterként... kész.
Követők feldolgozása (1/3): docs/architecture.md... kész.
Követők feldolgozása (2/3): docs/api.md... kész.
Követők feldolgozása (3/3): docs/install.md... kész.

Találatok (3)
────────────────────────────────────────────────────────
Fájl                  Sor  Súlyosság    Probléma
────────────────────────────────────────────────────────
docs/architecture.md  14   Eltérés      "item"-et használ; a README ugyanerre "task"-ot
docs/api.md           52   Elavult ref  /docs/config.md-re mutat — fájl átnevezve: /docs/setup.md
docs/install.md       88   Ellentmondás Node 18+ szükséges; README szerint Node 20+
────────────────────────────────────────────────────────

3 probléma találva 3 fájlban.

Kapcsolódó eszközök

  • /documentation-standard — Dokumentumstruktúrát érvényesít: hová kerülnek a fájlok, milyen szakaszok szerepeljenek. Futtasd az /md-reviewer előtt, hogy a struktúra rendben legyen.
  • /doc-voice — A szöveg hangnemét szabályozza: probléma-elsőként, bizonyíték-vezérelten, marketingszlogen nélkül. Javítja a stíluseltéréseket, amelyeket az /md-reviewer jelez.
  • /da-review — Egymenetes adversáris felülvizsgálat; használd az /md-reviewer után, ha egy második véleményt szeretnél arról, hogy a javítások helyesek-e.
