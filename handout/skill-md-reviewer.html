Summary

Docs drift — terms shift, cross-references rot, contradictions accumulate. /md-reviewer audits Markdown for consistency, contradictions, and stale links before readers find them. Handles sets of 50+ files with resumable progress tracking, and validates follower docs against an authoritative master.

When to use

Use /md-reviewer when docs have grown beyond what you can eyeball — terminology has drifted, you suspect contradictions between pages, or cross-references may have gone stale after a rename. It covers: terminology consistency, logical contradictions, cross-reference validity, formatting standards, voice/tone analysis, technical accuracy, and duplicate detection.

Trigger phrases (from SKILL.md):

  • "review my documentation"
  • "check docs for inconsistencies"
  • "validate markdown files"
  • "find contradictions in docs"
  • "audit documentation quality"

Master-follower mode: nominate one doc as the authority (e.g. README.md) and all others are checked against it. Findings are tagged by severity — contradiction, drift, stale ref, formatting.

Invocation

Invoke directly, then describe the docs to review — or paste file paths:

/md-reviewer

The skill asks two setup questions before starting: which files to review, and whether one file is the authoritative master. For large sets (50+ files), it tracks progress so you can pause and resume without restarting.

Related tools

  • /documentation-standard — Enforces doc structure: where files go, what sections to include. Run before /md-reviewer to get structure right first.
  • /doc-voice — Governs prose voice: problem-first, proof-led, no marketing fluff. Fixes the writing style /md-reviewer flags as voice-drift.
  • /da-review — Adversarial one-pass review; use it after /md-reviewer when you want a second opinion on whether the fixes are sound.
